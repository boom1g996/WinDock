## 2. 设计决策

| # | 决策 | 理由 / 约束 |
| --- | --- | --- |
| D1 | 沿用模式 C 为默认，M2 **不实机隐藏原生任务栏**；`TaskbarInterop.Hide/Restore` 保持可调用但不由组合根触发 | M0 判定为「降级」，Build 26200 超兼容矩阵（K-03）；AC-10/11 的恢复逻辑用快照模拟验证 |
| D2 | 新增能力全部通过 `IXxxService` 接口接入，实现放在 `WinDock.Core`，组合根 `App.xaml.cs` 唯一处 `new` | 需求 14.2 禁止模块互相引用实现；M1 已验证该边界 |
| D3 | 所有延时与动效（放大 / 跳动 / 指示点淡入淡出 / 滑入滑出 / 面板淡出）**统一走 `AnimationEngine` 的单一 `CompositionTarget.Rendering` 时间轴**；延时调度收敛到一个 `ITimerScheduler`，禁止每个功能/图标起独立 `DispatcherTimer` | 需求 14.3；M1 因 60FPS 空转踩过 21% CPU 的坑（K-01 修复记录） |
| D4 | `schemaVersion` **保持 1**，新增配置字段全部带默认值 | 需求第 9 章「未知字段忽略」；语义未变，不需要迁移，旧配置可读 |
| D5 | 热区按 **Dock 实际所在边动态生成**，与原生任务栏边缘解耦；用 2px 隐形热区窗口 + 鼠标位置检查，**不装全局钩子** | M0 §3 第 7 项降级 + 本机任务栏在顶部、Dock 在底部的实测事实；需求 8.6 |
| D6 | DWM 缩略图由 `IPreviewService` 独占 `HTHUMBNAIL` 生命周期（SafeHandle 包装），最多 6 个、面板关闭即 `DwmUnregisterThumbnail`；最小化窗口用最后快照 + 半透明遮罩 | FR-402/404、R7；M2 预研实测注册/注销 `S_OK` |
| D7 | 全屏检测 = `SHQueryUserNotificationState`（含 `QUNS_RUNNING_D3D_FULL_SCREEN` / `QUNS_PRESENTATION_MODE`）+ 前台窗口 rect 覆盖整屏双判据；命中即隐藏 Dock、禁用热区、暂停图标动效。**修订（第二批实测）**：QUNS 无公开变更通知，改为「前台切换 / 最小化还原 / `EVENT_SYSTEM_MOVESIZEEND` 事件驱动立即判定 + 3s 低频兜底确认」；1s 版本实测把稳态空闲 CPU 推到 0.7%，3s 仅为状态兜底 | FR-603；M0 §3 第 6 项 + M2 预研 + 第二批实机 |
| D8 | Watchdog 为**独立进程 + 命名管道心跳**，10s 无心跳则恢复任务栏并提示；不注册服务、不提权、不注入 | AC-11、8.2、8.6；M0 §3 第 15 项 |
| D9 | 所有新增 P/Invoke 集中到 `NativeMethods`（partial 类型，M2 声明在 `NativeMethods.M2.cs`），`SetLastError=true`，失败处取 `Marshal.GetLastWin32Error()`，并留手测/自检记录 | 需求 14.4 |
| D10 | 内存 120MB 指标**不通过禁用硬件加速凑数**：先做托盘去 WinForms 化（≈20MB）+ 实测复核，仍超则作为产品决策项提交确认 | M1 实测 Intel 显卡驱动约 162MB 模块映射；软件渲染会毁掉 ≥55FPS（AC-21） |

## 3. 模块与接口边界（新增）

| 接口 | 职责 | 关键约束 |
| --- | --- | --- |
| `IPreviewService` | 注册/更新/注销 DWM 缩略图，输出 160×90 基准画面与窗口标题（**第三批已落地**） | ≤6 个；`IDisposable`；面板关闭必须注销；`ApplyConfig` 调小上限时立即释放多余句柄 |
| `IAutoHideController` | 自动隐藏状态机、边缘热区、全屏检测、滑入滑出 | 复用 `IAnimationEngine`；热区按 D5；`SetHeld(reason, held)` 按 reason 引用计数，供浮层叠加抑制 |
| `IFullScreenDetector` | QUNS + rect 双判据，输出 `FullScreenStateChanged` | 无轮询，事件驱动（前台/显示变更事件） |
| `IDockDragService` | 固定项重排 / 拖出取消固定 / 运行项转固定，顺序写回 `Pinned`（**第四批已落地**） | 索引是 `Pinned` 列表插入位置；持久化走 `IConfigService.Save`；UI 手势改用 pointer capture（§4.4 修订） |
| `IStartupGuide` | 3 步引导（说明 → 共存模式 → 预设预览）（**第三批已落地**） | 默认 C；`General.FirstRunCompleted` 标记；任何关闭路径都要落标记 |
| `IIconCache` | `%LocalAppData%\WinDock\IconCache\` 磁盘缓存，key = 路径 + mtime + 尺寸 | mtime 变化失效；冷启动 ≤300ms |
| `IWatchdogService` | 独立进程心跳、主进程退出后恢复任务栏（**第四批已落地**） | 10s；心跳在 UI 线程派发，正常退出发 `S` 帧；仅模式 A 下恢复有实义，模式 C 下验证检测链路 |
| `IMetricsService` | 本地打点 + 1Hz→2s CPU 采样与突发归因（**第五批已落地**） | 计数/耗时内存聚合，归因行写本地日志；采样线程独立于 UI，不上报（8.6） |
| `ITrayIconService` | 纯 Win32 托盘：Shell_NotifyIcon + 原生右键菜单 + 气泡（**第五批已落地**） | message-only 窗口；菜单每次弹出重建；替代 WinForms NotifyIcon |
| `ITimerScheduler` | 单一延时调度（500ms 悬停 / 800ms 隐藏 / 3s 全屏兜底 / 滑入滑出收尾） | 唯一 Timer，不新增 DispatcherTimer |
| `IDockWindowHost` | Dock 窗口对自动隐藏控制器的窄接口（位移 / 可见性 / 命中测试 / 指针进出事件） | Core 层不引用 WPF `Window`（需求 14.2） |
| `IHotZone` | 2px 原生分层热区窗口的显隐与尺寸 | 幂等显隐，避免重复 `ShowWindow` 触发窗口枚举回环 |
| `IHotkeyService` | `Ctrl+Alt+D` 注册 / 注销 | 仅 `RegisterHotKey`，可卸载 |

`AnimationEngine` 已扩展 `Bounce` / `Attention` / `StopBounce` / `SetIndicatorStates` / `Slide` / `ConfigureMotion` 与 `IsRunning` / `SlideOffset`，`AnimationFrameEventArgs` 增加垂直跳动位移、指示点透明度与整条 Dock 滑出位移三个通道；仍由组合根单点注入，`DockIconControl` 只接收帧数据、不自持动画。
