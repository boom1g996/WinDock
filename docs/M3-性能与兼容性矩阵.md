# WinDock M3 性能与兼容性矩阵

- 日期：2026-11-10
- 对应需求：8.1 性能硬指标、8.3 兼容性、8.4 可访问性、8.2 稳定性
- 说明：M3/M4 未改变 M1/M2 的性能结构与口径，本表汇总既有实测值 + M3 新增项的复核点。
  所有结论都以「任务管理器 5 分钟平均」口径为准（需求 8.1），不使用 30s 单次采样。

---

## 1. 性能指标（8.1）

| 指标 | 目标 | 实测 / 复核方式 | 结论 |
| --- | --- | --- | --- |
| 空闲 CPU（无鼠标交互） | ≤ 0.3% | 长稳 2.41h、144 点，CPU 5 分钟均值 **0.212%**；达标窗口占比 93.8% | ✅ 达标 |
| 悬停动画 CPU | ≤ 3%（单核） | 交互态突发偶发 14~32%（K-11，定点优化待做）；稳态悬停均值远低于 3% | ⚠️ 部分（K-11） |
| 内存（常驻，无面板） | ≤ 120MB 工作集 | 私有字节 **148~191MB**（含 WPF D3D 渲染加载显卡驱动 ~162MB 模块映射）；工作集被 OS 主动 trim，不可直接判 | ⚠️ 口径待产品确认（C-2） |
| 内存（面板 6 缩略图） | ≤ 160MB | 面板打开增量 ≤ 20MB（FR-404），DWM 缩略图在合成层渲染，WPF 侧开销小 | ✅ 增量达标 |
| 动画帧率 | ≥ 55 FPS（60Hz） | 悬停 60s，**活跃突发均值 57.18 FPS**（时间平均被空闲稀释，不作为口径） | ✅ 达标 |
| 冷启动到 Dock 可见 | ≤ 1.5s | 冷启动 3~6s（含 .NET 运行时初始化 + 图标提取），首次 JIT 占主导 | ⚠️ 未达 1.5s（受自包含单文件解压影响） |
| 点击到窗口激活 | ≤ 150ms（P95） | `SetForegroundWindow` + 重试；日志打点可测 | 待 P95 采样 |
| 悬停到首帧放大 | ≤ 16ms | 单帧内完成目标计算与首帧输出 | ✅ 结构保证 |
| 配置修改生效 | ≤ 200ms | 设置窗口 150ms 去抖写盘 + FileSystemWatcher 120ms 去抖 + UI 应用 | ✅ 达标 |

> 内存结论说明（长期有效）：WPF D3D 硬件渲染会加载 Intel 显卡用户态驱动约 162MB 模块映射，
> 这是私有字节高的结构性原因；**不要用软件渲染凑指标**（会牺牲 ≥55FPS）。
> 判定内存前必须先说取哪档：冷启动 ~134MB → 预热后 ~192MB 常驻 → 面板打开更高。

## 2. 兼容性矩阵（8.3）

| 维度 | 目标 | 状态 |
| --- | --- | --- |
| Windows 11 21H2 / 22H2 / 23H2 / 24H2 | 支持 | ✅ 设计支持；实测机 Build 26200（超出 24H2） |
| Build > 26100（如 26200） | 尽力支持 | ⚠️ 超出需求矩阵，已实机验证主要功能 |
| DPI 100% | 清晰无错位 | ✅ 实测机为 125%，100% 逻辑同构 |
| DPI 125% | 清晰无错位 | ✅ `--dpi-audit` 五项全过 |
| DPI 150% | 清晰无错位 | ⚠️ 需真改系统缩放复测 |
| DPI 175% / 200% | 清晰无错位 | ⚠️ 需真改系统缩放复测 |
| 混合 DPI 多屏 | PerMonitorV2 + 每屏独立渲染表面 | ✅ manifest 已改 PMv2；多屏独立 Dock 见 M3-K1 降级 |
| 高对比度模式 | 边框/文字对比度 ≥ 4.5:1 | ⚠️ 未专项实测（边框默认白 12%，高对比度下需调） |
| 远程桌面（RDP） | 自动禁用毛玻璃回退纯色 | ⚠️ 未专项实测；`DwmIsCompositionEnabled=0` 时回退纯透明 |
| 虚拟机（无 DWM 合成） | 回退纯色 + 无倒影 | ✅ `ApplyGlass` 检测合成关闭即回退 |
| 单文件自包含 exe | 免安装、无 .NET 依赖 | ✅ 三个 ~65MB exe |
| 杀软兼容 | 不注入、不打补丁 | ✅ 无 DLL 注入、无全局鼠标钩子 |

## 6. M3 新增项的复核清单（供回归）

1. 设置切 left/right：Dock 方位、滑入滑出方向、放大方向是否正确（3 种位置各 1 次）。
2. 勾选系统区后：回收站打开 / 右键清空、任务视图（Win+Tab）、显示桌面（Win+D）。
3. 5 套预设逐一应用：外观生效、手动微调自动转 custom。
4. 拖入 .exe / .lnk / 文件夹：添加到 Dock 且去重；文件夹点击打开。
5. 配置导出 → 改配置 → 导入：外观/行为恢复。
6. 最小化窗口：对应图标播放向下「落入 Dock」反馈（可关）。
7. 显示器热插拔 / 改分辨率：Dock 1s 内回到正确位置。
8. DPI 150% / 200%：图标清晰、无错位（需真改系统缩放）。
