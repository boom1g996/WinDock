- 版本：M3 正式版（P1）+ M4 增强（P2）
- 日期：2026-11-10
- 对应需求：`需求文档.md` v1.0 第 11 章 M3 / M4
- 构建：`dotnet build src/WinDock.sln -c Release` → **0 警告 0 错误**

## 4. 已知问题与降级项

| 编号 | 项 | 说明 | 影响 |
| --- | --- | --- | --- |
| M3-K1 | 多显示器「每屏一条 Dock」 | 当前为**单 Dock 跟随所选显示器**（`MonitorIds[0]`，默认主屏，可填 1/2…切到副屏）+ 热插拔重排；同时多条 Dock 未启用。原因：多 Dock 需要 N 套动画/热区/自动隐藏实例，改动面大、回归风险高，留待专项评估 | 中（副屏需手动指定） |
| M3-K2 | 模式 B「精简共存」 | `coexist` 保留完整原生任务栏；未自动隐藏搜索/任务视图/小组件按钮（避免改注册表/系统设置）。用户可在 Windows 设置里自行精简 | 低 |
| M3-K3 | Jump List | 读取依赖目标应用的 AppID；大量应用的自动目标为空时不显示「最近/常用」分组（属预期降级，不影响菜单其余项） | 低 |
| M3-K4 | PerMonitorV2 | manifest 已改为仅 PMv2；150%/200% 需真改系统缩放复测（与 M2 AC-12 遗留一致） | 低 |
| M3-K5 | 垂直 Dock 细节 | 左/右 Dock 的指示点仍在图标下方（macOS 侧边 Dock 的指示点位置未单独适配）；放大/跳动方向已按方位处理 | 低 |
| M3-K6 | 最小化反馈 | 仅对「当前 Dock 中已存在的图标」播放；应用首次启动的窗口最小化若不在此列则不播放 | 低 |

## 5. 与 M1/M2 的兼容性

- 配置 schemaVersion 保持 **1**；M3/M4 新字段全部带默认值，旧 `config.json` 可直接读取，未知字段忽略（需求第 9 章）。
- 所有新增动效仍走单一 `AnimationEngine`，未新增独立渲染循环或 `DispatcherTimer`。
- 所有 P/Invoke 集中在 `NativeMethods`（M3 新增 `NativeMethods.M3.cs`）。
- 动效/自动隐藏/全屏抑制等既有行为未改变，默认（底部 Dock）与 M2 一致。
