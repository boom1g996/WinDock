## 5. 本批顺带修复的既有缺陷

1. **跨线程配置热更新**：`ConfigService` 的 `FileSystemWatcher` 回调在线程池 Timer 上，外部改 `config.json` 会让 `MainWindow.ApplyConfig` 抛 `InvalidOperationException`（首次第四批冒烟日志实证）。组合根改为 `Dispatcher.InvokeAsync` 切回 UI 线程；修复后 `log_errors_late=[]`。
2. **拖放结束误启动应用**：WPF 通用 `PreviewMouseUp` 早于控制器的 `PreviewMouseLeftButtonUp` 到达图标，抬手会触发 `Launch`。新增 `SuppressClick` 位，在本次按下→抬起期间拦截点击。
3. **配置重建打断手势**：拖拽期间 `RefreshItems` / `ApplyConfig` 会销毁源控件，改为延迟到落点后补做。
4. **`HWND_BROADCAST` 不可达隐藏窗口**：`--exit` 改为按 PID 定向投递到所有顶层窗口；实机对比广播无效、定向有效。
5. **退出时热键注销 WARN**：HWND 已销毁的 `Win32Error=1400` 属系统自动释放登记，不再记为告警。
