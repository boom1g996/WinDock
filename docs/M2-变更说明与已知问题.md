## 1. 可运行程序

| 项 | 内容 |
| --- | --- |

## 3. 验证结果（2026-11-09 实机，Win11 Build 26200 双屏）

| 项 | 结果 |
| --- | --- |
| Release 构建 | **0 警告 / 0 错误**（.NET 10.0.403） |
| 离线自检 | **21/21 PASS** |
| 功能冒烟 `docs/M2-smoke-batch3.json` | **PASS**：引导窗口 600×450 出现 → 关闭 → `firstRunCompleted=true`；预览面板 `[630,878,820,1032]` 出现并在鼠标移开后关闭；无日志 ERROR |
| 日志 | 无本次启动后的 `[ERROR]`；DWM 注册成功场景可见「DWM 注册=1」 |
| 冷启动 CPU 时间 | 1.016~3.703s（多轮，含引导窗口与 WM_CLOSE 交互），历史基线 1.0~1.4s |
| 空闲 CPU（交互后 20s） | `0.312%`，4 个 5s 分段均为 0.312%（约等于计时器 1 个时钟滴答/5s 的量化下限） |
| 空闲 CPU（纯稳态 30s） | `docs/M2-smoke-batch3-idle-trace.json`：分段 `[0, 0.312, 10.0, 0, 1.562, 0]%`、均值 **1.979%**；`docs/M2-smoke-batch3-idle.json`：均值 1.406%。**未达到 8.1 的 ≤0.3%**，见 K-13，不伪装达标 |
| 工作集内存 | 典型 212~240MB（浮层在场时），曾采到 30.89MB 的系统 trim 瞬时值；**未达到 ≤120MB**，见 K-01 / K-14 |

> 回归现场 `docs/M2-smoke-batch3-initial.json` 保留首次冒烟的 27.187% 空闲 CPU 与反复打开的预览面板日志，用于验证 K-12 修复未回退。
