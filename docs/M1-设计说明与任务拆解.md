## 1. 设计说明（1 页）

### 1.1 目标与范围
M1 出口标准：**可日常使用 1 天不崩**。只做 P0 最小闭环：Dock 渲染 → 图标 → 点击启动/切换 → 悬停放大 → 右键菜单 → 基础设置 → 托盘 → 恢复原生任务栏。
M1 **不做**：缩略图预览、自动隐藏、拖拽排序、首次引导、看门狗、图标缓存（M2）；多显示器独立配置、主题预设、位置切换、i18n（M3）；更新器、Jump List（M4）。

### 1.2 技术栈与工程
`.NET 10 LTS + WPF`（`net10.0-windows10.0.22000.0`、`UseWPF=true`、`ApplicationHighDpiMode=PerMonitorV2`、`Nullable=enable`、`TreatWarningsAsErrors=true`），自包含单文件发布 x64/ARM64，不要求用户装 .NET。
> **版本修订说明**：需求文档 4.2 推荐 .NET 8，但微软官方支持策略显示 .NET 8 / .NET 9 均于 **2026-11-10 终止支持**（当前日期 2026-11-09），当前 LTS 为 .NET 10（支持至 2028-11-14）。4.2 属「推荐技术栈」而非功能约束，WPF / WindowsDesktop SDK 用法完全一致，故升到 .NET 10 LTS，不改变任何功能需求。
主进程 `DockHost` 常驻；`WinDock.Settings` 独立窗口；`WinDock.Watchdog` 留到 M2。P/Invoke 集中在各模块内部，一律带 `SetLastError` 与 `Marshal.GetLastWin32Error()`。

### 1.3 模块边界（第 14 章第 2 条，模块间只走接口）
`ConfigService` · `TaskbarInterop` · `WindowEnumerator` · `IconService` · `DockRenderer` · `AnimationEngine` · `PreviewService`(M2) · `SettingsUI` · `Watchdog`(M2)。
所有模块以 `IXxxService` 接口注入，禁止实现类互引；`App.xaml.cs` 为唯一组合根。

### 1.4 关键设计决策
| # | 决策 | 理由 |
| --- | --- | --- |
| D1 | **默认模式 C（仅美化）**，模式 A 需显式开启并二次确认 | 需求 0.4 + M0 实测：任务栏在顶部且 Build 26200 超出兼容矩阵；隐藏属非官方 API |
| D2 | `TaskbarInterop` 启动时 `GetWindowRect` 动态推断任务栏边缘，保存原 rect + 原状态，恢复时原样写回 | 实测任务栏在**顶部**、两块屏均有；硬编码「底部」会导致隐藏/热区/恢复全部错位 |
| D3 | 不注册 `SHAppBarMessage` AppBar | 悬浮胶囊不应改变工作区；避免与原生任务栏抢边（M0 §3-2） |
| D4 | 动画统一由 `AnimationEngine` 挂 `CompositionTarget.Rendering`，空闲即取消订阅 | 第 14 章第 3 条；满足 8.1「空闲 CPU ≤0.3%」；禁止每图标一个 DispatcherTimer |
| D5 | 放大用 `RenderTransform` + 手动水平位移补偿，不用 `LayoutTransform` | 避免每帧触发 WPF 布局；底边对齐、邻域余弦衰减、禁止重叠 |
| D6 | 窗口模型用 `SetWinEventHook`（CREATE/DESTROY/SHOW/HIDE/MINIMIZESTART）+ 启动全量扫描，无轮询 | 实测 419 个顶层窗口，轮询开销不可接受；必带 `DWMWA_CLOAKED` 过滤 |
| D7 | 配置原子写（临时文件 + `File.Replace`），`schemaVersion` + 未知字段忽略 + 越界夹紧 + 损坏回退默认并备份 | 需求 6.14 / 第 9 章约束 |
| D8 | 所有 UI 字符串外置 `.resx`，v1 中英双语 | 需求 8.5；代码内不硬编码文案 |
| D9 | 主程序**永不提权**；管理员窗口只提示不操作 | 需求 8.6 / M0 §3-9 |

### 1.5 状态与数据
状态机按第 7 章串行处理，M1 实现 `Visible / Hovering / Dragging(占位)`，`Hidden / Peeking / PreviewOpen` 留 M2。
配置落 `%AppData%\WinDock\config.json`，字段严格照第 9 章草案；图标先走内存缓存，磁盘缓存 M2 再做。
日志格式 `[模块][级别] 时间 消息`，本地 `%LocalAppData%\WinDock\logs`，保留 7 天，用户名脱敏。
